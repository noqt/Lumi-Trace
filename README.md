# Lumi Trace

Lumi Trace is a local vulnerability evidence instrument. This repository is
being prepared for a public Apache-2.0 release, but remains private while the
V0.1 implementation is reviewed.

No model checkpoint, hosted inference service, or API key is used.

## Status

V0.1 implementation is in progress on `codex/lumi-trace-v0-1`.
