# Changelog

## 0.2.0 - Evaluation and training-readiness qualification

- Added the separately packaged Python 3.11 Trace-Eval runner and verifier.
- Added canonical contracts for rights, groups, labels, splits, runs, attempts,
  raw seals, replay, metrics, controlled review, qualification, and readiness.
- Added fail-closed rights, lineage, exposure, holdback, leakage, and public
  boundary policy checks.
- Added exact V0.1 wheel verification, label-blind subprocess orchestration,
  bounded failure retention, deterministic replay, and tamper-evident packages.
- Added hand-calculated denominator, micro/macro, file/symbol/region,
  hard-negative, false-confirmation, timeout, replay, and tamper tests.
- Qualified only the public synthetic regression lane. Natural corpus scale,
  repository-disjoint qualification, and ranking thresholds remain pending.
- Recorded `ENVIRONMENT_QUALIFIED / DATA_GATES_PENDING` and preserved
  `DO_NOT_BEGIN_TRACE_001`.

## 0.1.0 - Initial public source release

- Added strict manual and SARIF finding import.
- Added immutable directory/archive snapshots and deterministic identities.
- Added deterministic file, token, and symbol indexing.
- Added transparent integer-scored candidate ranking.
- Added qualified Docker reproduction with external network denied.
- Added fail-closed evidence classification and JSON/SARIF export.
- Added sanitized resolved dependency/licence inventory and reproducible release
  evidence sealing.
- Added the inaugural `skylark.lumi.trace` inventory record with zero weights.
- Recorded `DO_NOT_BEGIN_TRACE_001` until every training evidence gate is met.

This version is the initial public source release. It contains no model weights
or training data and does not authorise `TRACE-001` training.
