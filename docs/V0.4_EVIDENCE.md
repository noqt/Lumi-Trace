# Lumi Trace V0.4 Evidence

V0.4 public evidence is sealed under `evidence/v0.4`. The seal is a
disclosure-safe aggregate projection of the governed corpus, frozen
comparators, conditional TRACE-001 experiment, single-use qualification, hard
stops, and closure.

Verify it from the repository root:

```powershell
python scripts/verify_v0_4_evidence.py evidence/v0.4
```

The manifest binds every public artifact by exact path, SHA-256, and byte
length. Verification also checks the unchanged V0.3.2 starting seal, corpus
floors, partition independence, qualification budget, training consistency,
public boundary, zero published weights, and unopened protected holdback.

This is a controlled internal release review. It is not a third-party audit.
The public seal intentionally omits repository and case identities, source,
labels, paths, symbols, revisions, diffs, private feature records, checkpoint
bytes, customer data, and holdback substance.

The final closure and exact aggregate results are authoritative in the sealed
JSON records. Repository publication, tags, releases, and weight publication
remain `NO_GO_PENDING_USER_REVIEW`.
