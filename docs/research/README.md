# Historical research

This directory preserves selected public research and evaluation records from
Lumi Trace's development. It is retained for transparency, including failed,
inconclusive, and superseded experiments.

This material is **not** the supported product contract. The root
[`README.md`](../../README.md), the [product documentation](../README.md), and
the published schemas describe current supported behaviour.

The research archive does not distribute private repositories, case-level
findings, labels, training data, model checkpoints, protected evaluation
material, or customer evidence. References to those classes of material record
historical controls and decisions; they do not indicate that the material is
present in this repository or licensed for reuse.

Historical implementation identities and evaluation outcomes may differ from
the current release. Do not use this archive to infer present product
capabilities, security guarantees, or release status.
