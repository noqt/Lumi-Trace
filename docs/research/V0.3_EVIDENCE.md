# V0.3 Public Qualification Evidence

The V0.3 evidence directory is a disclosure-safe projection of governed
private qualification records. It contains no natural repository content,
event content, customer material, model weight, training data, or host path.

After sealing, verify it with:

```powershell
$env:PYTHONPATH = "eval/src"
python scripts/verify_v0_3_evidence.py evidence/v0.3.0
```

The verifier enforces exact directory membership, artifact hashes and sizes,
canonical record identities, public-boundary policy, and these stop gates:

- programme state `DATA_GATES_PENDING`;
- no natural development or qualification run;
- frozen holdback unopened;
- `DO_NOT_BEGIN_TRACE_001`;
- no training or weights;
- Trace IR has no live integration, response action, or attack-detection
  claim; and
- publication remains `NO_GO_PENDING_USER_REVIEW`.

The public IR ratios are owned-lab contract tests. They must not be presented
as natural incident-response performance.
