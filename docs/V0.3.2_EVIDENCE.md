# Lumi Trace V0.3.2 Evidence

The disclosure-safe V0.3.2 seal is stored under `evidence/v0.3.2/` after the
governed build completes. It records the exact runtime and evaluator wheel
hashes, development and qualification decisions, resource envelope,
training-readiness decision, closure state, and public-boundary review.

Verify it from the repository root:

```console
python scripts/verify_v0_3_2_evidence.py evidence/v0.3.2
```

The seal contains no third-party repository source, finding text, labels,
target paths, candidate paths, symbols, raw outputs, repository revisions,
qualification case identities, or private host paths. Those records remain in
governed private storage.

The evidence seal—not this stable product document—is authoritative for the
final V0.3.2 capability and qualification outcome. V0.3.2 does not publish a
release or tag and does not authorise `TRACE-001` training.
